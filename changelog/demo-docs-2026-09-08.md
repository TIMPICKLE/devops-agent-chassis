## 演示边界

- 默认并发仍为 1，4 只是可配置的示例；共享候选提交不并行，模型不保证选择批次。
- example 07 使用测试 decider，验证实际工具重叠、独立判据和严格格式；示例不保存报告目录。
- 普通员工 CLI 自动记录 ReAct 遥测，严格来源绑定与检查回执仍需显式接入。
- 领导版结果表与技术版失败例子明确标注为示意；历史 live 运行继续关联各自受测版本。
- 知识更新演示使用单独的账单基线，包含一次新的模型生成；只有更新操作本身为零模型调用。
