基于用户已完成的 T01（`f6fadb8`），保留统一装配入口、配置校验和 Windows 补丁换行修复。

## 问题与实现

- 区分并行未开启、工具未声明并行安全、未知工具、重复/非法调用 ID、非法参数、批次超限及任务预算不足。
- 核心提供零依赖 `ToolDiagnostic`；适配器保持 `ModelError` 接口，并携带同样的结构化诊断。
- 调用位置使用 1 起始序号；只显示已注册工具名称和 schema 声明的字段路径/约束类型。不输出模型给出的未知工具名、调用 ID、参数值或原始 schema 异常。
- 诊断进入 `RunContext.diagnostics`、模型失败记录和可移植证据；v1 schema 添加可选字段，旧证据继续可读。
- 整批预检、失败 token 保留和零工具执行行为保持不变。不修改 T05 范围内的 HTTP 诊断。
